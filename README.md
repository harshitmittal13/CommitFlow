# CommitFlow

CommitFlow is a resolution engine designed to help people keep the track of commitments with full record.

Instead of acting as a traditional CRUD application, chatbot, complaint-management system, or simple AI wrapper, ResolvePath is designed around a resolution workflow:

initial Commitments → Approval → Request of update requiments → Response of the new updated details → Approval → Resolution / Escalation / Closure

## Current MVP

The first concrete workflow is:

**Small buisness or independent Workers**

The Interior designer is the first problem domain used to build and validate the broader CommitFlow platform.

The architecture is intended to support additional real-world problem workflows in the future.
